\# Engineering Guidelines



\## Project Rules

\- Follow the actual client brief.

\- Never invent requirements or achievements.

\- Prefer simple, maintainable architecture.

\- Avoid unnecessary dependencies and infrastructure.



\## Backend

\- Validate all inputs.

\- Enforce authentication and authorization.

\- Handle errors consistently.

\- Keep business logic testable.



\## Frontend

\- Responsive design.

\- Consistent UI.

\- Implement loading, empty and error states.

\- No dead buttons or fake functionality.



\## AI

\- Never fabricate AI outputs.

\- Handle uncertain and invalid results.

\- Validate structured outputs.



\## Testing

\- Test important business logic.

\- Run tests after meaningful changes.

\- Fix root causes rather than hiding errors.



\## Security

\- Never commit secrets.

\- Use synthetic sample data.

\- Never trust client-side authorization.



\## Workflow

\- Work in small milestones.

\- Review changes before committing.

\- Document assumptions and limitations.

\- Never claim an unimplemented feature works.
